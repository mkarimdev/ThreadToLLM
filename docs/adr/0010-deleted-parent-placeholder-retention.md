# Deleted Parent Placeholder Retention

The Filter Pipeline preserves pruned parent comments as minimalist redacted placeholders when they contain active child replies, while completely pruning orphaned leaf branches. This applies to deleted or removed comments and to automated/bot comments alike. Completely discarding such comments inadvertently destroys insightful human discussion trees that hung off the pruned parent; retaining a concise placeholder maintains conversational hierarchy and sources without cluttering the output with the pruned node's own noise.
