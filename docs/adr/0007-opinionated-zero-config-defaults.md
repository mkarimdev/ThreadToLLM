# Opinionated Zero-Config V1 Filtering

For V1, ThreadToLLM operates without user configuration or a settings popup, enforcing opinionated defaults (pruning AutoModerator, removing deleted/removed comments, and capping reply depth at 3 tiers). Providing a configuration popup and synchronization storage upfront increases V1 surface area and cognitive friction; shipping opinionated zero-config defaults delivers an instant one-click workflow while establishing the core baseline.
